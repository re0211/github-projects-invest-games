# GitHub 开源项目梳理 · 投资 × 游戏制作 × 游戏拓展

一份面向实践的项目地图：从 GitHub 筛出活跃、可落地的开源项目，按「投资量化」「游戏制作」「游戏拓展与解包」三条线梳理，逐项评估可拓展性与实用性。

## 内容结构

1. **投资与量化** — 数据层 / 回测层 / AI 与策略层 / 实盘层 / 组合优化
2. **游戏制作** — 通用引擎 / 视觉小说引擎 / Godot 生态 / AI 辅助开发
3. **游戏拓展与解包** — 通用资源浏览器 / 分引擎解包工具 / MOD 框架 / 实时翻译
4. **推荐组合与落地路线** — 三条可选的组合路径
5. **避坑与合规** — 维护状态、License、过拟合、解包合规

## 评分口径

- **可拓展性**：二次开发、脚本化、接入自有系统的难度（越高越容易扩展）
- **实用性**：当下就能解决问题的程度

## 数据来源

GitHub Search API 与 Repository API，抓取时间 2026-09-01。星级、更新时间、开源协议均为实测值。
