#### A1. 《1 分钟，让你的网站充满吸引力！》—— 鱼皮（程序员鱼皮），2024-11（juejin post id 7439232445470359552）
- URL：https://juejin.cn/post/7439232445470359552 （同文另见腾讯新闻转载 https://news.qq.com/rain/a/LNK2024111900201900 ）
- **核心**：用 `stevenjoezhang/live2d-widget` 一行 `<script src=".../autoload.js">` 给网站挂看板娘；但默认从作者远程服务器拉模型，**想换自己的模型就得搭 PHP 后端**。鱼皮的解法：把仓库下到本地，**复制 `autoload.js` 与模型定义文件，改成本地加载**（`isLocalModel:true`、`modelsPath`、`modelListPath` 三项指向本地 `model/`），再 `npm run build` 重打包；模型放根目录，`model_list.json` 用二维数组（外层=模型、内层=皮肤）。
- **两个真坑**：① 直接双击 html 打开会失败 —— 浏览器禁止 `file://` 直载资源，**必须起本地服务器**（`serve` 或 IDE 内置服务器）；② 模型文件通常几 MB~几十 MB，静态站挂上去**很吃带宽/流量**（鱼皮自己也在纠结要不要上线）。
- **可复用性：✅ 落地**。基准人设（静态索引站 + 个人开发）**几乎逐条对得上**：离线自托管看板娘的正确姿势就是「改 autoload 本地化 + 起静态服务器」，不需要任何后端；`better-coder` 仓库可直接抄。⚠️ 注意 `live2d-widget` 是 **GPL-3.0**（索引 [r31] 已记），商业站要小心传染。

#### C1. 《live2d 动画制作简述以及踩坑》—— 夏琰 · 网易云社区（sq.sf.163.com，2018-10-15）
- URL：https://sq.sf.163.com/blog/article/210180786409922560
- **核心**：**老版工作流（Cubism Modeler + Animator + Viewer 三件套）的一手踩坑**。免费版**图层数不能超 30**，所以切图要精打细算「哪块做表情、哪块做四肢、哪块可合并」；蒙皮控制器父子关系是 **旋转 ＞ 曲面 ＞ 曲线 ＞ 点**；**三维世界轴的 X 旋转，在 Live2D 里对应的是 Z 轴**（因为 2D 工具）；术语实操：把原画角度设为「0 点动画」，角度 X 插 3 点、绿点拖左右两端再挪控制器。作者血泪心得：**PSD 原稿过大要先转智能对象再缩放、别在 Live2D 里改尺寸**；**务必检查控制器下部件的父子关系**；蒙皮时改部件 ID 方便程序读取；**动画时间轴不要留空帧**；`.moc` 重改后动画文件要关掉重开才会自动更新。
- **可复用性：⚠️ 参考**。**老版本（2.x/Modeler 时代）**，术语与 5.x 不对应，**不能照抄操作**；但「父子层级=旋转>曲面>曲线>点」「X/Z 轴换算」「先补图再布点」这些**概念级经验仍然成立**，是理解「为什么模型一动就散」的好材料。
