### 02. AITuberKit 故障排除 · Live2D 模型加载 TypeError（中文文档）
- 链接：https://docs.aituberkit.com/zh/guide/troubleshooting
- 出处：AITuberKit 官方文档（中文版）· 作者/机构未核实 · **发布日期未核实**
- 核实方式：`WebFetch <url>` 得到正文全文
- 一句话：官方把「自制模型在 AITuberKit 里渲染不出来」这个高频问题的**根因和绕法**写清楚了，是中文圈少见的、给出确切导出参数组合的排错文档。
- 具体内容（逐字）：
  - 报错：`TypeError: Cannot set properties of undefined (setting '_currentFrameNo')` at `Cubism4InternalModel.updateWebGLContext`
  - 根因：`pixi-live2d-display` 系库的已知 bug——**模型里没有任何一个 ArtMesh 开启「生成蒙版」时，`_clippingManager` 不会被创建，变成 `undefined`**；另外，**Cubism 5 格式（.moc3 v4）导出的模型与该库不兼容**。
  - 解法（三步）：① 选任意 ArtMesh → [检查器] ▶ [绘制] ▶ **生成蒙版** 打开；② [文件] ▶ [导出] ▶ 模型(.moc3)，导出设置选 **SDK: SDK for Web / 版本: Cubism 4.2（或 4.0/4.1）**；③ model3.json 的 **Groups 里加 `EyeBlink` 和 `LipSync`**（不加不报错，但表情和口型不生效）。
  - 提示：只需在眉毛或高光这类轻量网格上开蒙版即可；也可建一个不可见的小网格专门开蒙版。
- 可拓展性：**这条与条目 01 是同一个 `_currentFrameNo` 报错的两个独立解法**（01 是换官方 SDK，02 是开蒙版+降版本导出）。两条合起来就是一个完整的决策树：先试开蒙版（1 分钟），不行再换 SDK（1 小时）。另外「Cubism 5 导出的模型第三方库未必吃」这条，和上一辑条目 08 里卡米雷特的警告互相印证。
- 实用性：**落地**。理由：这是本轮最可直接抄的一条——任何人导出模型给第三方播放器/引擎前，都应该先看「有没有至少一个蒙版」和「导出 SDK 版本选没选对」。

### 12. 物理摆锤参数的官方口径（用于校正中文圈的野数字）
- 链接：https://docs.live2d.com/en/cubism-editor-manual/physical-operation-setting/

### 三句话总结
1. **上一辑的「知乎零命中」是方法错误不是源死了**——把域名当普通关键词丢进 Bing 再 WebFetch，知乎专栏正文**无需登录即可直取**；本轮据此拿到 2 条（其中《Live2D模型的简单制作》指出了上一辑 28 条都没提到的官方「应用模板」捷径）。反过来，**gamemale 是真的进不去**：反爬挑战页 + 两大引擎索引量近 0 + 站点定位是 furry/同性向成人社区而非建模社区，三重原因，本轮 5 个入口全试仍零命中，不编。
2. **本轮最硬的产出是两条「同一报错的两个独立解法」**——CSDN《数字人应用技术探索（三）》和 AITuberKit 官方中文文档，都撞在 `Cannot set properties of undefined (setting '_currentFrameNo')` 上：一个的解法是换官方 SDK，另一个是「给任意一个 ArtMesh 开生成蒙版 + 导出时选 SDK for Web / Cubism 4.2」。配上官方手册的物理参数口径（Length / Ease of swinging 0.7~0.99 / Reaction time / Speed of convergence），**可以直接证伪中文圈流传的「阻尼 0.3-0.5、重力 2.5-3.5」那套数字——软件里根本没有叫「阻尼」「重力」的参数**，这是本轮最省时间的一条。
3. **AI 侧的结论是「拆图能用、成模不能」**：ComfyUI-See-through（LayerDiff SDXL + Marigold，24 层带遮挡补全）是真家伙且可复现，但**显存门槛未核实**，对 16GB 内存的学生要先确认显卡；而「一张图全自动出成品」已被 note.com 那位作者用 29 部件 / 23 次测试亲手证伪——**失败的根因是「立绘本身不含让它动起来的信息」**，这反推出的实操建议比任何 AI 工具都值钱：**要动，就得从原画阶段按可动来画**（对照上一辑那位「画完才想起做 Live2D，硬拆 14 小时」的画师）。至于「Cubism 5.0 有 AI 面部自动生成」这类说法——官方 5.3/5.4 的新功能清单里没有，**是编的**。
