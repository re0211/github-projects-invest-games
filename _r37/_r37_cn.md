### A1. easy-live2d：基于 Pixi.js 封装的轻量级 Live2D Web SDK（掘金 · 2025-05-05 · easy-live2d 作者）
- URL：https://juejin.cn/post/7499977945203015717
- 核心：把 Live2D 操作简化为「像操控 pixi sprite 一样」。支持 **Pixi.js v8 + Cubism 5**；**不打包 Cubism Core**——因 Live2D 政策，需自行去官网下 `Live2D Cubism SDK for Web`，把 **`Core/` 目录放进 `/packages/cubism/`**。安装 `pnpm add easy-live2d`；入口 `<script src="/Core/live2dcubismcore.js">`。给了原生 HTML / Vue3 两套完整最小示例，`Config.MotionGroupIdle='Idle'`、`Config.MouseFollow=false`、`live2DSprite.onLive2D('hit', …)`。**评论区有 MooreThreads 的 GPU 工程师反馈：`guansss/pixi-live2d-display` 长期不维护、issue 无人回，才转投此库**——这条评论比正文更有信息量。
- 可复用性：**落地** —— 已维护索引站要加看板娘／AI 角色时，这是「不改一行渲染代码」的最短路径；注意 Core 需自取、npm 包不含模型。

### A2. easy-live2d v0.4.0 — 全面进化的 Live2D Web 开发体验（掘金 · 2025 · 同作者）
- URL：https://juejin.cn/post/7624422672950149158
- 核心：v0.4.0 内部几乎重写（单体 → monorepo，门面模式＋控制器分离＋事件总线）。量化卖点：「**5 行代码加载模型，1 行代码播放语音口型同步**」，`await sprite.playVoice({voicePath:'/sounds/hello.mp3'})` 即自动 RMS 口型。**新增：Cubism 3/4/5 全版本模型兼容**（老资源不再报「加载不了」）；**渲染冲突修复**（Live2D 现在就是一个普通 Pixi Sprite，可与 UI/背景层叠）；新增 **Tauri 支持**（桌宠/桌面助手）；支持 mp3/wav/ogg **及远程音频 URL**（可直接对接 TTS）。音频格式「所有浏览器可解码格式」。
- 可复用性：**落地** —— 「TTS → 远程 URL → 一行口型」正是本地 LLM＋Ollama 角色站的刚需；这是本辑 cn 路唯一「自带 RMS 口型同步」的现成 Web 方案。

### A3. Asoul 二次元日系插件制作工具经验分享 — 利用 live2dSDK 接入教程（掘金 · 2022 · —）
- URL：https://juejin.cn/post/7094960290609152031
- 核心：直接给**头发物理的代码级参数**——`PhysicsHair.setup(0.2f, 0.5f, 0.14f)`，三个入参依次是「长度（公尺，影响摆动周期）／空气阻力／头发重量」；再 `physicsHairSide.addSrcParam(PhysicsHair.Src.SRC_TO_X, "PARAM_ANGLE_X", 0.005f, 1)` 把「角度 X 变动」以 **0.005 倍影响度**输入摆锤。模型是「两侧＋后侧」三段头发就分 `physicsHairSide / physicsHairBack` 两个对象。含眼睛跟随鼠标 `setParamFloat("PARAM_EYE_BALL_X/Y", …)`。
- 可复用性：**⚠️ 参考** —— 用的是老 SDK 的物理 API，新 SDK 已换 `CubismPhysics`；但**「长度/阻力/重量三参 + 输入影响度」这套口径可跨版本迁移**，是理解摆锤物理最快的数字锚。
