### 7. 抖音《【Live2D教程】1.3 省流版总结：动态壁纸的制作全过程》
- **URL**：https://www.douyin.com/shipin/7298778568094468122
- **作者/来源**：抖音 Live2D 教程账号（视频号未显示）
- **日期**：未核实
- **具体结论**：**拆分与布点的工程级规范**，本轮最细的一份：
  - **蒙版**：限制显示范围的运动必须额外提供一个蒙版图层，使用时把不透明度调到 **0**；做法是复制蒙版图层 ID → 在需要剪贴的图层上粘贴该 ID → 回车。
  - **循环动画**：首尾必须有一段重复帧（「前五帧是 A，最后五帧也必须是 A」）才能无缝循环。
  - **夹在中间的标签**：前后两条线要各自单独拆出，否则旋转时会卡在接缝。
  - **眼睛**：拆成眉毛/上睫毛/双眼皮/侧睫毛/下睫毛/卧蚕/眼白/瞳孔/高光；**瞳孔要尽量是完整的圆或椭圆**，沿瞳孔外围 + 真实瞳孔形状补点。
  - **窄条状物体**用「按笔触划分网格」一次点出路径生成 **2 或 3 排点**；**宽条状要布 4 排点就做两次**（上两排 + 下两排）；眼白用自动布点即可。
  - **嘴部**：上嘴线/上嘴皮/下嘴线/下嘴皮/上牙/下牙/舌头/后牙/口腔；**上嘴线与上嘴皮要有部分重复补点**（下同理），否则运动边缘不一致；**上牙无需补点**（只做位移不做变形）。
  - **手**：每一根手指单独一个图层，沿关节布点。
  - **腿**：小腿要拆成「线条 / 阴影 / 底色」三层，让线条和底色**夹住**阴影层，防止阴影改变勾线颜色；阴影绘制时要**溢出小腿范围**，之后打蒙版限制显示。
  - **植物/背景**：不必每层单独，多条放同一层交错即可；纯背景层**不用补点**。
- **核实状态**：⚠️ 视频页未直连，但搜索返回完整口播转写，内容可回溯。
- **可复用性**：① 落地 —— 这是本轮唯一给出「几排点 / 哪几层夹哪几层 / 重复补点区间」这种可验收颗粒度的中文教程，能直接转成给建模师的 checklist。
