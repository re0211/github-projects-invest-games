
==================== GitHub 30 ====================
* 1. Compresr-ai/Context-Gateway
    放在编码 Agent 与模型 API 之间的 Go 代理，在历史真正超窗前后台预压缩，到触发点直接换入已算好的摘要。
* 2. big0lives/codex-task-pointer
    用“目标 + 下一步”的小型任务指针和 Codex hooks，让长任务跨自动压缩后重新锚定主线。
* 3. sdwolf4103/opencode-working-memory
    把 OpenCode 自带 compaction 顺手用于记忆抽取，分开维护跨会话 workspace memory 与当前会话 hot state，不额外调用模型。
* 4. disler/self-compact-pi-agent
    让 Pi Agent 看见自己的上下文用量，在软提醒、警告、硬截止三道阈值间主动写 `note_to_self` 并触发压缩。
* 5. GlitterKill/sdl-mcp
    把代码仓库索引为符号图和紧凑“卡片”，再按任务切片、预算取回，而不是让 Agent 一上来读整文件。
* 6. nguyenvuthientrang/cliffcompaction
    透明 API 代理在请求越过 token 阈值时，把旧历史替换成“开头原文 + 单条摘要 + 最近若干轮”。
* 7. MarceloCaporale/codex-agent-mem
    本地 SQLite + FTS5 的 MCP 记忆层，把目标、约束、未完事项和快照压成有预算的 context pack，按需给 Codex、Claude Code、Gemini CLI 等取回。
* 8. ZKiteLM/pi-trace-viewer
    给 Pi 会话做本地实时显微镜，展示分支、工具调用、压缩切点、摘要输入及真正发给模型供应商的 payload。
* 9. codecoradev/uteke
    单 Rust 二进制的本地 Agent 记忆引擎，用 ONNX 嵌入与混合检索在 CPU 上完成存储、召回和 MCP 服务。
* 10. RamaAditya49/titen
    不用 API key、LLM 或默认向量服务的 Agent 记忆服务，兼容 MCP reference memory 的工具名，并给每条记忆保留来源、权限与反证。
* 11. OnlyTerp/prompt-cache-skills
    逐个审计编码 Agent harness 的请求组装方式，并提供可移植技能来修复缓存断点、动态时间戳和缺失 cache key。
* 12. Just-Agent/make-agents-cheaper
    用 Rust CLI 审计 Codex 的提示层、工具 schema 与缓存断点，对比普通配置和 cache-friendly 配置的实际账单输入。
* 13. lllq-123/claude-code-cache-keepalive
    一份带实测读数的 Claude Code 长会话缓存保活手册，说明哪些操作会让 cache read 归零，以及如何在 TTL 前低成本续命。
* 14. dean0x/skim
    用 AST 理解代码结构，并压缩测试、构建、git diff 与命令输出的 Rust 上下文优化器。
* 15. codeus-morbid/contextmaxxer
    本地 Go MCP 检索器用小型编码器、符号关系与明确 token budget 返回带行号的代码证据。
* 16. WeiYe6/dsh-session-handoff
    `/handoff` 让 LLM 总结 DSH 当前会话，创建同工作区的新 session + agent，注入交接文档后自动打开。
* 17. liangmianya/dsh-synapse
    把同一工作区的 DSH 会话、追问与 fork 投影成可拖拽缩放的地图，并保持原生 session log 为唯一事实源。
* 18. AdamPlatin123/dsh-plugin-radar

* 19. tintinweb/vscode-pi-model-chat-provider

* 20. PIsberg/vibetags

* 22. EricSun0218/OpenGameAgent
